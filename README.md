# Interval Timer

A simple circuit / interval workout timer for the browser. Configure work and rest times, circuits, and rounds; run fullscreen with pause, skip, and hold-to-adjust controls.

**Live app:** https://lmlhordijk.github.io/work-out-timer/

## Run locally

Requires [Bun](https://bun.sh).

```bash
bun install
bun run dev
```
